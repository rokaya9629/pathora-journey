# Pathora: Your Career Compass

Build a modern full-stack SaaS web application called "Pathora".

Tagline:

"From Student to Professional"

Pathora is an AI-powered student growth platform that helps students discover career paths, build skills, find opportunities, create professional portfolios, and track progress toward their future goals.

Use:

- Next.js App Router

- TypeScript

- Tailwind CSS

- shadcn/ui

- Supabase Authentication

- Supabase Database

- Responsive Design

- Dark/Light Mode

Create a professional startup-quality UI.
